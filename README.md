# Two Heberts, Remembered

A static memorial site for Sergeant Robert J. Hebert (Korean War) and Corporal Yvon Andre Hebert (Vietnam War).

Live site: https://murpheylawe.github.io/hebert-memorial/

## Enable The Film section

1. Place `videos/two-heberts-remembered.mp4` (45 MB or less) and `videos/two-heberts-poster.jpg` in this repo.
2. In `index.html`, change `<body data-film-ready="false">` to `<body data-film-ready="true">`.
3. Commit and push. The Film section and its nav link will appear after the hero.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.
